# Как запустить приложение локально

## Шаг 0. Установите Node.js (один раз)

Нужен **Node.js версии 18 или новее** (рекомендуется 20 LTS).

- Windows / macOS: скачайте установщик с https://nodejs.org и запустите его.
- Проверка после установки (в командной строке / терминале):

```bash
node -v   # должно показать v18+ (например v20.x.x)
npm -v    # покажет версию npm
```

## Шаг 1. Распакуйте архив

Распакуйте архив в любую папку, например `C:\prizyv` или `~/prizyv`.
Внутри должны быть файлы `package.json`, `server.ts`, папки `src` и `index.html`.

## Шаг 2. Откройте терминал в папке проекта

- **Windows**: откройте папку в Проводнике, кликните по адресу сверху, напишите `cmd` и нажмите Enter.
- **macOS / Linux**: откройте Терминал и перейдите в папку: `cd путь/к/папке`

## Шаг 3. Установите зависимости (один раз)

```bash
npm install
```

Займёт 1–3 минуты. Появится папка `node_modules` — это нормально.

## Шаг 4. Запустите приложение

```bash
npm run dev
```

Дождитесь строки вида:

```
Server listening on http://0.0.0.0:3000
```

## Шаг 5. Откройте в браузере

👉 **http://localhost:3000**

Загружайте PDF — распознавание работает полностью локально, без Gemini и без интернета.

## Частые проблемы

**«npm не является внутренней командой»** (Windows)
→ Node.js не установлен или терминал открыт до установки. Установите Node.js и перезапустите терминал.

**«EADDRINUSE: address already in use 3000»**
→ Порт 3000 занят другим процессом. Запустите на другом порту:

```bash
# Windows (cmd)
set PORT=3001 && npm run dev

# macOS / Linux
PORT=3001 npm run dev
```

и откройте http://localhost:3001

**«'sh' не является внутренней командой» / ошибки npm на Windows**
→ используйте PowerShell или Git Bash вместо cmd.

**Хочу остановить сервер**
→ нажмите `Ctrl+C` в окне терминала.

## Настройки (не обязательно)

Создайте файл `.env` в корне проекта (можно скопировать из `.env.example`):

```
PORT=3000
```

`GEMINI_API_KEY` задавать **не нужно** — распознавание чертежей выполняется локальным движком (`pdfjs-dist`). Ключ Gemini нужен только если захотите включить AI-анализ сканированных изображений.
